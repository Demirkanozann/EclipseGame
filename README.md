🐦 Flappy Bird (Java Swing)
Bu proje, Java Swing kullanılarak geliştirilmiş basit bir Flappy Bird oyunudur. Oyuncu, engellerin arasından kuşu geçirerek mümkün olduğunca yüksek skor elde etmeye çalışır.

🚀 Özellikler
Java Swing ile oluşturulmuş grafik arayüz
Akıcı oyun döngüsü
Klavye ile kuş kontrolü
Engel sistemi
Skor takibi
Basit ve anlaşılır proje yapısı
🛠️ Kullanılan Teknolojiler
Java
Java Swing
